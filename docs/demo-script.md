# Three-minute local demo

Start the server using the README. The video can use replay without credentials.
Read actual labels; do not manufacture a Pass or policy failure.

## 0:00–0:25 — Purpose

“Whatiff generates counterfactual observations and records policy behavior for
physical AI evaluation. The input is a real first-person dishwashing photo.”

## 0:25–1:10 — Replay

Click **Replay saved example** and point to the recorded/live provenance label.

“These decisions were recorded from live Meta calls. Replay itself makes zero
model calls. Compare the original with an occlusion, a distractor, and a relocation.”

## 1:10–1:45 — Decisions and limits

Switch tabs; expand **Why this action?** once.

“The recorded policy selected PICK_TARGET. Needs review means this record is not
yet verified. The edits changed resolution; no normalization or physical execution
was validated. Model explanations alone do not prove correctness.”

## 1:45–2:25 — Review

Show the separate approval sections. If entering a demo approval, identify it as
your current review, not recorded validation.

“Edit approval and expected-action approval are separate. Failed checks persist
even after approval. Expected actions must be defined independently.”

## 2:25–3:00 — Data

Click **Export JSON**, then **Generated Data** (Finder on macOS; manually open the
path elsewhere). Show the compact JSON and the original/edited images.

“The output contains relative image paths, actions, verification states, outcomes,
and evidence IDs. Detailed audit history stays separate. Failure discovery is
one downstream application.”

Optional live run: use your own Meta key. API latency varies; the three-minute
video should not depend on fresh live completion.
